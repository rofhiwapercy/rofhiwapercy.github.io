Overview

Turning student data into a prediction.

This project explores whether selected student characteristics can be used to classify an academic outcome. The notebook uses the UCI Student Performance dataset and builds a binary target: Pass when the final grade is at least 10, otherwise Fail.

The selected inputs are study time, previous grade and absences. A Decision Tree is trained first, followed by a Random Forest to examine model performance and feature importance.

Dataset

UCI Student Performance

The notebook identifies the dataset as the UCI Student Performance dataset, originally based on secondary-school students in Portugal.

Reported study-time category, encoded from 1 to 4 in the notebook.

02

The student's previous grade, used as prev_grade.

03

TARGET

Pass / Fail

Methodology

From raw data to classification.

01

Select

The notebook combines the feature and target data, then keeps the variables needed for the experiment.

02

Prepare

A binary results target is created from the final grade.

03

Train

The data is split 80/20 and a Decision Tree with maximum depth 3 is fitted.

04

Compare

A 100-tree Random Forest is trained to compare performance and inspect feature importance.

Results

How the models performed?

MODEL 01 Decision Tree

Decision Tree

92.5% Training accuracy
91.5% Test accuracy

The notebook limits the tree depth to 3 to keep the learned structure readable and reduce the risk of memorising the training data.

MODEL 02 100 trees

Random Forest

95.4% Training accuracy
90.8% Test accuracy

The Random Forest uses 100 trees and is then used to examine how much each selected feature contributes to the model.

Feature Importance

What mattered most to the Random Forest?

The notebook reports the following feature-importance values from the trained Random Forest.

Previous grade 73.57%
Absences 21.28%
Study time 5.15%

Decision Tree

The model can be read as rules.

One useful advantage of a Decision Tree is that its decisions can be inspected as a sequence of conditions.

YES

NO
